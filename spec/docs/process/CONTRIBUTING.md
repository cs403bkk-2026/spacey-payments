# Working agreement

- Create a branch for every change.
- Open a pull request; do not push directly to `main`.
- Explain what changed, why, and how you checked it.
- Review one another's work before merging.
- Link product, architecture, data, and deployment decisions from GitHub.
- Never commit credentials, tokens, private keys, or `.env` files. This repository is public.

When blocked, post in Slack immediately with:

1. the command or GitHub Actions link;
2. the observed output;
3. what you already tried; and
4. the help you need.
